# 阅伴 · 产品构想笔记

> 创作素材库 / 快速笔记 · 用于演示 Markdown 真实渲染与划词提问

## 核心价值

「读一本书 / 一篇论文时，**问题留在原文处**，想法按原文归档」——把 AI 问答从「窗口」变成「原文的一部分」。

## 差异化四要素

1. **本地安装** · 隐私优先，断网可用
2. **全格式高保真**预览（P0+P1 共 28 个格式族）
3. **划词锚定**问答，问在哪标在哪
4. 本地 + API **双模型**配置

## 用户场景

| 场景    | 典型用户      | 关键诉求                  |
| ----- | --------- | --------------------- |
| 科研精读  | 研究生、科研人员  | 划词提问、锚点回看、术语解释        |
| 合同审阅  | 律师、产品经理   | 对条款提问并留痕              |
| 素材库阅读 | 创作者、知识工作者 | epub / xmind / 代码统一阅读 |
